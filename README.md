# Terraria Compendium

Guia visual de Terraria em português brasileiro, com progressão por chefes e recomendações por classe (Melee, Ranger, Mage e Summoner).

O código da versão v0.6 será importado para este repositório, com a branch `main` reservada para versões estáveis e `develop` para desenvolvimento e testes.

Projeto independente feito por fãs, sem afiliação com a Re-Logic.
